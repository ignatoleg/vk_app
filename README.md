# Матчи спортивного клуба (VK Mini App)

## Как запустить

1. Зарегистрируй мини‑приложение на dev.vk.com (тип — Mini App). Скопируй `App ID`.
2. Создай папку на компьютере, положи туда `index.html`, `vk-hosting-config.json`, `README.md`.
3. В `vk-hosting-config.json` замени `"app_id": 0` на твой `App ID`.
4. Загрузи папку на хостинг:
   - Проще всего: GitHub + Netlify (перетащил папку — получил ссылку).
   - Или используй VK Hosting для мини‑приложений (через CLI).
5. В настройках приложения на dev.vk.com вставь URL, который дал хостинг (обязательно HTTPS).
6. Включи доступ «для всех» и сохрани.

## Как добавлять матчи

В файле `index.html` найди массив `matches` и добавляй/меняй матчи по образцу.

- `status`: `"upcoming"` (предстоит), `"completed"` (сыгран), `"cancelled"` (отменён).
- Для сыгранного матча укажи `score` как строку, например `"3:2"`.
- Матчи автоматически сортируются и попадают на нужную вкладку.
